## Multi-User Chat Application

A real-time client-server chat system built using Java, JavaFX, Socket Programming, Multithreading, and MySQL. The application allows multiple users to communicate through public/private messaging and file sharing with secure user authentication.

# Features
User Registration & Login
Real-time Messaging
Private Chat
File Transfer
Active Users List
Multi-threaded Communication
MySQL Database Integration
Modern JavaFX GUI

# Technologies
Java
JavaFX
MySQL
JDBC
Socket Programming
Multithreading
