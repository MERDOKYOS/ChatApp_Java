# Multi-User Chat Application
A real-time client-server chat application built using Java, JavaFX, Socket Programming, Multithreading, and MySQL.
The system allows multiple users to communicate simultaneously through public and private messaging while supporting secure authentication and file sharing.

# Features
- User Registration & Login Authentication
- Real-time Group Chat
- Private Messaging
- Active Users Panel
- File Transfer System
- Multi-threaded Server & Client Communication
- MySQL Database Integration
- JavaFX Modern GUI
- Chat History Storage
- Responsive Background Threading
- Technologies Used
- Java
- JavaFX
- Socket Programming
- Multithreading
- JDBC
- MySQL
- Scene Builder
- CSS Styling
- System Architecture

## The application follows a client-server architecture where:

The server manages client connections, message broadcasting, and file transfers.
Clients communicate with the server through sockets.
MySQL stores users, messages, and transferred files.
